

# 💳 Loan Risk Prediction System

## 📌 Project Overview

This project is an AI-powered Loan Risk Prediction System developed using Python, SQL, Power BI, and Streamlit.

The application analyses customer financial behaviour and predicts loan repayment risk based on:
- Credit Score
- Monthly Income
- Delinquencies
- Missed Payments
- Credit Enquiries
- Loan Type

---

✅ Loan Risk Prediction
